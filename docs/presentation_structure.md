# СТРУКТУРА ПРЕЗЕНТАЦИИ ПРОЕКТА «ОКО МЧС»
## Шаблон слайдов для Сони к защите перед жюри

### Слайд 1. Титульный (Вау-эффект)
* **Заголовок:** ОКО МЧС: Автономный БПЛА-комплекс раннего обнаружения и ликвидации природных пожаров
* **Подзаголовок:** Компьютерное зрение • Автопилот • ЦУКС в реальном времени
* **Команда:** Название команды, капитан, роли (Архитектура, UI, Компьютерное зрение, Симуляция).
* **Визуал:** Крупный рендер дрона над лесным массивом с тепловизионной сеткой.

### Слайд 2. Проблема (Боль МЧС)
* **Статистика:** Ежегодно лесные пожары в РФ уничтожают миллионы гектаров леса, ущерб исчисляется миллиардами рублей.
* **Главный вызов:** Обнаружение пожара на ранней стадии (площадь до 0.5 га), когда его можно потушить силами одного ранцевого расчета.
* **Недостатки текущих решений:**
  - Спутники: обновляют данные раз в несколько часов, не видят сквозь плотную облачность.
  - Пилотируемая авиация (Ми-8, Ан-2): крайне дорого (от 150 000 руб./час), не может патрулировать 24/7.
  - Наземные вышки: ограничены радиусом прямой видимости и рельефом.

### Слайд 3. Наше решение («Око МЧС»)
* Автономный комплекс на базе легкого квадрокоптера с бортовым ИИ-анализом видеопотока.
* **Ключевые фичи:**
  1. Автоматический облет зоны по сетке («змейка») без участия оператора.
  2. Двойной спектр: оптическая 4K-камера + тепловизор для поиска сквозь дым.
  3. Бортовая детекция пламени за 0.2 секунды.
  4. Мгновенная передача координат очага на пульт ЦУКС МЧС.

### Слайд 4. Архитектура системы
* **Схема взаимодействий:**
  - Симуляция: Gazebo 11 (физика полета, аэродинамика, 3D-мир леса и рельефа).
  - Связующее ядро: ROS 2 Humble (микросервисная шина обмена сообщениями).
  - Зрение: OpenCV + HSV-сегментация + фильтрация шума.
  - АРМ Оператора: Нативное десктоп-приложение с тактической картой и телеметрией.

### Слайд 5. Алгоритмы зрения и расчет координат
* Как работает алгоритм Ромы:
  - Выделение цветового спектра пламени (HSV).
  - Морфологический фильтр (устранение ложных срабатываний от бликов солнца).
  - Формула триангуляции: расчет координат очага по высоте полета $Z$ и положению рамки на матрице камеры.

### Слайд 6. АРМ Оператора (Интерфейс Сони)
* Скриншоты реального работающего интерфейса:
  - Панель живой камеры.
  - Режим тепловизора.
  - Карта патрулирования с треком полета БПЛА.
  - Лог событий и автогенерация карточки происшествия.

### Слайд 7. Экономика и масштабирование
* **Стоимость системы:** около 350 000 руб. за один комплект БПЛА + пульт.
* **Экономический эффект:** Экономия до 85% бюджетных средств по сравнению с вертолетным патрулированием.
* **Предотвращенный ущерб:** Одно своевременно локализованное верховое возгорание экономит до 50 000 000 руб. ущерба лесному фонду.
