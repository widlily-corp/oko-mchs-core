# 🗺 Большая реалистичная арена «Око МЧС» (200×200 м)

## Что изменилось

Старая арена была плоской площадкой ~100×100 м с четырьмя примитивами.
Новая карта генерируется скриптом `src/mchs_simulation/scripts/generate_arena_world.py`
и включает:

| Зона | Объекты |
|---|---|
| База МЧС (0, 0) | бетонная вертолётная площадка с разметкой H и огнями, ангар, мачта связи с маяком, контейнеры, пожарная техника |
| Дорожная сеть | две магистрали с разметкой, сервисные дороги, стоянка, мост через реку |
| Река | русло 240 м, песчаные берега, мост с опорами и ограждением |
| Лесной массив (СВ) | 34 дерева, кустарник, очаг пожара с выгоревшей зоной, пламенем и дымом |
| Нефтебаза (СЗ) | 4 резервуара с обваловкой, трубопроводы, насосная, эстакада, разлив нефтепродуктов |
| Посёлок / склады | 6 жилых домов, 2 склада, поля, дворы |
| Зона затопления (ЮВ) | водоём с рябью, затопленная техника |
| Полигон ТБО (ЮВ) | холм мусора, 10 бочек, обломки, ограждение, токсичная свалка |
| Ландшафт | поля-«пэчворк», холмы по краю карты, деревья и кустарник |

Площадь мира — **200×200 м** (плоскость 240×240 м), небо и тени настроены в `<scene>`.

## Координаты очагов ЧС (для `arena_controller.py`)

| Код | Модель | X | Y |
|---|---|---|---|
| `fire` | `fire_hazard` | 60.0 | 28.0 |
| `oil` | `oil_spill_hazard` | -58.0 | 30.0 |
| `flood` | `flood_hazard` | 45.0 | -56.0 |
| `waste` | `waste_hazard` | 68.0 | -72.0 |

```bash
# Переместить очаг в любую точку арены (на лету, без перезапуска Gazebo)
python3 src/mchs_simulation/scripts/arena_controller.py --hazard fire --x 10 --y 5
# Перетасовать все объекты ЧС
python3 src/mchs_simulation/scripts/arena_controller.py --random
```

## Полёт

Дрон стартует на высоте **22 м** (в модели `mchs_drone` отключена гравитация,
чтобы кинематический плагин `libgazebo_ros_planar_move` держал эшелон).
Маршрутный автопилот `src/mchs_control/scripts/mchs_pilot_route.py` облетает
точки наблюдения (за 18 м до очага — так камера видит очаг в кадре):

```
БАЗА (0,0) → ПОЖАР (42,28) → НЕФТЕБАЗА (-76,30)
           → ЗАТОПЛЕНИЕ (27,-56) → ПОЛИГОН ТБО (50,-72) → БАЗА
```

Крейсерская скорость 14 м/с, зависание над каждой точкой 4 с, цикл повторяется.
FSM-автопилот Артёма (`mchs_pilot_node.py`) не изменялся и покрыт тестами.

## Запуск демо

Из Windows одной командой:

```powershell
.\run_all.bat            # или: powershell -File run_all.ps1
```

Скрипт поднимает в WSL `gzserver` с новой ареной, ноду зрения с HTTP-стримом
камеры (`http://localhost:8080`), маршрутный автопилот и открывает АРМ оператора
на Windows (`src/mchs_ui/app.py`).

Ручной запуск:

```bash
# WSL
source /opt/ros/humble/setup.bash
bash scripts/run_all.sh            # MCHS_NO_UI=1 — без автозапуска окна
```

```powershell
# Windows
python \\wsl.localhost\Ubuntu-22.04\root\oko-mchs-core\src\mchs_ui\app.py
```

## Проверено

* `gzserver` загружает мир без ошибок, камера публикует 1280×720 @ 30 FPS;
* дрон реально пролетает весь маршрут (телеметрия `/mchs/odom`);
* HTTP-стрим отдаёт аннотированный кадр с детекцией FIRE/OIL/FLOOD/WASTE;
* АРМ на Windows получает поток и показывает его в панели камеры;
* `arena_controller` перемещает очаги через `/gazebo/set_entity_state`.

## Известные ограничения

* WSLg выводит окна X11 (gzclient) за пределы экрана — 3D-окно Gazebo не
  показываем, весь визуал идёт в АРМ и веб-стрим;
* детектор визуальных сцен (модуль `mchs_vision`) может давать ложные
  срабатывания на тёмных/серых поверхностях новой карты — пороги настраиваются
  в `src/mchs_vision/mchs_vision/config.py`;
* 49-МБ модель `largedrone` (STL) не включена в новую арену: основной
  летающий носитель — `mchs_drone` с ROS 2-камерой.
