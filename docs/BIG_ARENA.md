# 🗺 Большая реалистичная арена «Око МЧС» (200×200 м)

## Что изменилось

Старая арена была плоской площадкой ~100×100 м с четырьмя примитивами.
Новая карта генерируется скриптом `src/mchs_simulation/scripts/generate_arena_world.py`
и включает:

| Зона | Объекты |
|---|---|
| База МЧС (0, 0) | бетонная вертолётная площадка с разметкой H и огнями, ангар, мачта связи с маяком, контейнеры, пожарная техника |
| Дорожная сеть | две магистрали с разметкой, сервисные дороги, стоянка, мост через реку |
| Река | русло 240 м, песчаные берега, мост с опорами и ограждением |
| Лесной массив (СВ) | 34 дерева, кустарник, очаг пожара с выгоревшей зоной, пламенем и дымом |
| Нефтебаза (СЗ) | 4 резервуара с обваловкой, трубопроводы, насосная, эстакада, разлив нефтепродуктов |
| Посёлок / склады | 6 жилых домов, 2 склада, поля, дворы |
| Зона затопления (ЮВ) | водоём с рябью, затопленная техника |
| Полигон ТБО (ЮВ) | холм мусора, 10 бочек, обломки, ограждение, токсичная свалка |
| Ландшафт | поля-«пэчворк», холмы по краю карты, деревья и кустарник |

Площадь мира — **200×200 м** (плоскость 240×240 м), небо и тени настроены в `<scene>`.

## Координаты очагов ЧС (для `arena_controller.py`)

| Код | Модель | X | Y | Описание |
|---|---|---|---|---|
| `fire` | `fire_hazard` | 60.0 | 28.0 | Очаг лесного пожара (калиброванный расчёт площади) |
| `oil` | `oil_spill_hazard` | -58.0 | 30.0 | Разлив нефтепродуктов |
| `flood` | `flood_hazard` | 45.0 | -56.0 | Зона затопления / паводка |
| `waste` | `waste_hazard` | 68.0 | -72.0 | Токсичные отходы / бочки химреагентов |
| `human` | `person_standing` | 15.0 | -22.0 | Пострадавший (человек в сигнальном жилете) |

```bash
# Переместить очаг в любую точку арены (на лету, без перезапуска Gazebo)
python3 src/mchs_simulation/scripts/arena_controller.py --hazard fire --x 10 --y 5
# Перетасовать все объекты ЧС
python3 src/mchs_simulation/scripts/arena_controller.py --random
```

## Полёт

Дрон стартует на высоте **22 м**. В модели `largedrone/model.sdf` у link
отключена гравитация (`<gravity>false</gravity>`), иначе дрон медленно
проседает, а кинематический плагин `libgazebo_ros_planar_move` не удерживает
эшелон. Маршрутный автопилот `src/mchs_control/scripts/mchs_pilot_route.py`
сканирует всю арену змейкой — план полёта и параметры ниже.

## Сканирование арены

Автопилот `mchs_pilot_route.py` больше не летает по 4 точкам: он сканирует
**всю арену змейкой** по плану из `config/mission.json` (по умолчанию 7 рядов
по X с шагом 28 м по Y, скорость 12 м/с, около 2 минут на полный проход).
Очаги при этом не «теряются»: ряды y = −84, −56, −28, 0, 28, 56, 84 проходят
рядом с каждым из четырёх очагов. Текущее положение дрона, ряд, прогресс и
детекции АРМ получает по `http://127.0.0.1:8080/state.json`.

Очаги можно перетаскивать мышью на тактической карте АРМ: координаты
сохраняются в `config/hazards.json`, а модели в Gazebo переезжают на лету
через `arena_controller.py`. Отчёты — в `reports/` (фото очагов, снимки
оператора, видео, протоколы). Подробности — в [`LIVE_SCAN_DEMO.md`](LIVE_SCAN_DEMO.md).

## Запуск демо

Из Windows одной командой:

```powershell
.\run_all.bat            # или: powershell -File run_all.ps1
```

Скрипт поднимает в WSL `gzserver` с новой ареной, ноду зрения с HTTP-стримом
камеры (`http://localhost:8080`), маршрутный автопилот и открывает АРМ оператора
на Windows (`src/mchs_ui/app.py`).

Ручной запуск:

```bash
# WSL
source /opt/ros/humble/setup.bash
bash scripts/run_all.sh            # MCHS_NO_UI=1 — без автозапуска окна
```

```powershell
# Windows
python \\wsl.localhost\Ubuntu-22.04\root\oko-mchs-core\src\mchs_ui\app.py
```

## Проверено

* `gzserver` загружает мир без ошибок, камера `largedrone` публикует
  1280×720 @ 30 FPS, `odom.z` стабильно 22.0 м;
* дрон реально пролетает весь маршрут (телеметрия `/mchs/odom`);
* HTTP-стрим отдаёт аннотированный кадр с детекцией FIRE/OIL_SPILL/FLOOD/SMOKE;
* АРМ на Windows получает поток и показывает его в панели камеры;
* `arena_controller` перемещает очаги через `/gazebo/set_entity_state`;
* регрессия зрения на 6 реальных кадрах Gazebo: пожар/нефть/затопление
  находятся, вертодром/база/полигон ТБО — без ложных событий.

## Известные ограничения

* WSLg выводит окна X11 (gzclient) за пределы экрана — 3D-окно Gazebo не
  показываем, весь визуал идёт в АРМ и веб-стрим;
* детектор HSV чувствителен к освещению и материалам: пороги вынесены в
  `src/mchs_vision/mchs_vision/config.py`, реальные кадры закреплены в
  `src/mchs_vision/tests/data/`;
* класс `WASTE` (свалка/бочки) в зрении не детектируется: полигон ТБО
  используется автопилотом как точка маршрута, а не как класс ЧС;
* 49-МБ модель `largedrone` подключена к арене через `model://largedrone`;
  для запуска нужен `GAZEBO_MODEL_PATH=src/mchs_simulation/models`.
