# Отчёты «ОКО МЧС» — куда всё сохраняется

Каталог `reports/` — единое место для всех материалов полёта. На Windows он же
открывается по UNC-пути `\\wsl.localhost\Ubuntu-22.04\root\Rep\oko-mchs-core\reports`
(кнопка «📂 ОТЧЁТЫ» в АРМ и сочетание клавиш `Ctrl+O`).

| Каталог | Что внутри | Кто пишет |
|---|---|---|
| `incidents/` | Фото очагов с тактическим HUD (JPEG 1280×720, имя = `INC-…_ЧЧММСС.jpg`) — фотодоказательства детекции | нода зрения (WSL) |
| `photos/` | Ручные снимки оператора с бортовой камеры (`snapshot_ГГГГММДД_ЧЧММСС.jpg`) | АРМ (Windows) |
| `video/` | Видеозаписи оператора (`record_ГГГГММДД_ЧЧММСС.mp4`, MP4, 12 кадр/с) | АРМ (Windows) |
| `incident_protocol.json` | Последний протокол инцидента для автоподхвата АРМ (пишется бортом/зрением) | нода зрения, автопилот |
| `incident_protocol_*.json/.txt` | Ручной экспорт протокола оператором (JSON и печатный бланк TXT) | АРМ |
| `mission.cmd` | Файл-команда автопилоту: `scan` — продолжить сканирование, `rtl` — возврат на базу | АРМ (удаляет автопилот) |

Служебные журналы лежат рядом:

| Путь | Что внутри |
|---|---|
| `logs/system.log` | Общий журнал комплекса (все подсистемы, включает CRITICAL/WARNING) |
| `logs/events.jsonl` | Машиночитаемые события (JSON Lines) |
| `logs/gcs_ui.log` | Журнал АРМ оператора |
| `logs/stdout/gazebo.log` | Консоль gzserver |
| `logs/stdout/vision.log` | Консоль ноды зрения |
| `logs/stdout/pilot.log` | Консоль автопилота |

> Каталог `reports/` не коммитится в git (оперативные артефакты полёта), в
> репозитории хранится только этот README.
