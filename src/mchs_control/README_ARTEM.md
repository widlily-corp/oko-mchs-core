# ИНСТРУКЦИЯ ДЛЯ АРТЁМА (ПОЛЕТНЫЙ АВТОПИЛОТ & ОТЧЕТНОСТЬ)

Привет, Артём! Твоя задача — полетная программа дрона (облет сектора) и генерация официального протокола происшествия для спасателей.

---

## 1. Где лежат твои файлы:
* Полетный контроллер: `src/mchs_control/scripts/mchs_pilot_node.py`
* Генератор отчета МЧС: `src/mchs_control/scripts/generate_report.py`
* Шаблон пояснительной записки: `docs/technical_note_template.md`

---

## 2. Запуск и проверка:

### 1) Тест генератора протокола МЧС (работает и на Windows, и в Linux):
```bash
python src/mchs_control/scripts/generate_report.py
```
* В папке появится красивый JSON-файл `mchs_report_...json` со всеми реквизитами службы спасения.

### 2) Тест полетного контроллера (внутри WSL):
```bash
wsl.exe -d Ubuntu-22.04
python3 src/mchs_control/scripts/mchs_pilot_node.py
```
* Нода начнет циклично публиковать скорости полета БПЛА в топик `/mchs/cmd_vel`.

---

## 3. Твои задачи:
1. **Скрипт патрулирования «змейкой»:**
   * В `mchs_pilot_node.py` настрой тайминги фаз:
     - 0–3 сек: подъем
     - 3–15 сек: полет вперед по просеке
     - 15–20 сек: зависание над зоной
     - 20–35 сек: возврат на базу (RTL).
2. **Связка с отчетом:**
   * Сделай так, чтобы при зависании над очагом вызывалась функция `generate_incident_report(...)` и сохраняла отчет инцидента с актуальным временем.
3. **Пояснительная записка:**
   * Открой `docs/technical_note_template.md`, проверь характеристики дрона и дополни разделом по полетным режимам.
