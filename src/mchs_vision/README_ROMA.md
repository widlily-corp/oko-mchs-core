# БОЕВАЯ ИНСТРУКЦИЯ И ТЗ ДЛЯ РОМЫ (VISION LEAD)

Привет, Рома! Наше соревнование вышло на финальный этап. Мы создаем систему оперативного мониторинга ЧС с воздуха.
Твоя зона ответственности — **мозг компьютерного зрения**: обработка видеопотока с БПЛА, обнаружение ЧС, расчет площади и точных координат очага.

---

## 1. Контракт ввода-вывода (Интерфейс в ROS 2)

### Что принимает твоя нода:
- Топик видеопотока: `/mchs/camera/image_raw` (`sensor_msgs/msg/Image`)
- Топик телеметрии БПЛА: `/mchs/odom` (`nav_msgs/msg/Odometry`) — отсюда берем высоту дрона $Z$ и его текущие координаты $X, Y$.

### Что публикует твоя нода:
- Топик события ЧС: `/mchs/detection_event` (`std_msgs/msg/String`, сериализованный JSON):
  ```json
  {
    "hazard_type": "FIRE",
    "threat_level": "CRITICAL",
    "area_sq_m": 35.2,
    "target_geo": {
      "abs_x": 14.8,
      "abs_y": -5.2,
      "rel_x": 4.8,
      "rel_y": -1.2
    },
    "confidence": 0.95,
    "timestamp": "2026-11-11T12:00:00"
  }
  ```
- Аннотированный видеопоток: `/mchs/camera/annotated` (`sensor_msgs/msg/Image`) с тактическим оверлеем (рамки, тип ЧС, перекрестье прицела).

## 2. Твое ТЗ по пунктам (Что нужно реализовать)

### Задача 1: Мультиклассовая детекция (4 типа ЧС)
Вместо одного огня по регламенту хакатона мы детектируем 4 класса:
1. **Пожар (`FIRE`):**
   - Яркие желто-оранжевые тона в HSV: `H: [5..25], S: [120..255], V: [180..255]`.
   - Контурный фильтр: площадь $S > 250$ пикселей.
2. **Задымление (`SMOKE`):**
   - Светло-серые рассеянные тона: `H: [0..180], S: [0..45], V: [160..230]`.
3. **Разлив нефтепродуктов (`OIL_SPILL`):**
   - Темные пятна на траве/песке: `H: [0..180], S: [0..75], V: [15..65]`.
4. **Затопление / паводок (`FLOOD`):**
   - Сине-голубая водная поверхность: `H: [95..125], S: [80..255], V: [60..200]`.

### Задача 2: Оценка уровня угрозы (`threat_level`)
- Малое пятно ($< 15\text{ м}^2$) $\to$ `ADVISORY`
- Средний очаг ($15 - 50\text{ м}^2$) $\to$ `WARNING`
- Крупный очаг / верховой пожар ($> 50\text{ м}^2$) $\to$ `CRITICAL`

### Задача 3: Формула геопозиционирования (расчет координат)
По координатам центра рамки $(u, v)$ на изображении размера $W \times H$:
$$\Delta X = \frac{u - W/2}{W} \cdot Z \cdot 2 \tan\left(\frac{\text{FOV}_x}{2}\right)$$
$$\Delta Y = \frac{v - H/2}{H} \cdot Z \cdot 2 \tan\left(\frac{\text{FOV}_y}{2}\right)$$
Где для нашей камеры: $\text{FOV}_x \approx 1.396\text{ рад}$ ($80^\circ$).
Абсолютные координаты на полигоне:
$$X_{\text{hazard}} = X_{\text{uav}} + \Delta X$$
$$Y_{\text{hazard}} = Y_{\text{uav}} + \Delta Y$$

## 3. Как запустить и тестировать

Работай в отдельной ветке:
```bash
git checkout -b feature/vision-roma
```

Запуск ноды в WSL:
```bash
python3 src/mchs_vision/scripts/mchs_vision_node.py
```
*(При отладке можно открыть окно `cv2.imshow('MCHS Tactical Feed', frame)` для проверки визуализации вживую).*
