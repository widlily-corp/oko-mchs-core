# ИНСТРУКЦИЯ ДЛЯ РОМЫ (КОМПЬЮТЕРНОЕ ЗРЕНИЕ / CV LEAD)

Привет, Рома! Твоя задача — алгоритм компьютерного зрения, который принимает видеопоток с камеры дрона, обнаруживает очаг пожара/задымления и рассчитывает его координаты.

---

## 1. Где лежит код и как тестировать

Файл ноды: `src/mchs_vision/scripts/mchs_vision_node.py`

### Запуск внутри WSL2:
```bash
wsl.exe -d Ubuntu-22.04
python3 src/mchs_vision/scripts/mchs_vision_node.py
```
*(Также можно тестировать автономно на обычном видео или через вебкамеру, заменив чтение топика ROS 2 на обычный `cv2.VideoCapture(0)`).*

---

## 2. Что уже реализовано в стартовом файле:
1. Подписка на ROS 2 топик `/mchs/camera/image_raw` через `cv_bridge`.
2. Конвертация кадра в HSV и сегментация по цветовому порогу пламени (`lower_fire` / `upper_fire`).
3. Морфологическая зачистка шума (`MORPH_OPEN`, `dilate`).
4. Поиск контуров `cv2.findContours` и отрисовка рамки детекции `cv2.rectangle`.
5. Тактический HUD МЧС: статус тревоги, перекрестье прицела в центре, координаты рамки.

---

## 3. Твои задачи по развитию модуля:

1. **Тюнинг порогов HSV:**
   * Проверь работу на разных оттенках огня (желтый, оранжевый, ярко-красный) и дыма (серо-белые тона).
2. **Расчет смещения очага (Геолокация):**
   * В функции `image_callback` центр обнаруженной рамки:
     $cx = bx + bw / 2$
     $cy = by + bh / 2$
   * Посчитай отклонение от центра кадра $(w/2, h/2)$ в метрах (зная высоту БПЛА).
3. **Публикация события тревоги:**
   * Добавь публикацию JSON-строки в топик `/mchs/fire_detected` вида:
     `{"fire_detected": true, "box": [bx, by, bw, bh], "confidence": 0.94}`
   * По этому сигналу дрон Артёма зависнет над очагом, а на пульте Сони загорится сирена!
