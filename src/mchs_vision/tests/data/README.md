# Реальные кадры Gazebo для регрессии зрения

Кадры сняты с камеры `largedrone` (1280×720, HFOV 80°, наклон 45°) в
`worlds/mchs_emergency_arena.world`, высота 22 м. Это не синтетика
`simulated_scene.py`, а настоящий рендер Gazebo 11 — он проверяет HSV на
реальных материалах, освещении и тенях.

| Файл | Поза (x, y) | Что проверяет |
|---|---|---|
| `gazebo_fire_1280.png` | 41.76, 27.84 | пожар должен дать WARNING/CRITICAL |
| `gazebo_oil_1280.png` | -75.87, 29.92 | нефть есть, белые резервуары не дым |
| `gazebo_flood_1280.png` | 27.17, -56.12 | затопление есть, река не считается |
| `gazebo_waste_1280.png` | 49.53, -71.67 | свалка и река — без событий |
| `gazebo_helipad_1280.png` | -25.44, -0.18 | оранжевое кольцо не пожар |
| `gazebo_home_1280.png` | 0.25, -0.37 | крыши, окна, техника — без событий |
| `gazebo_containers_1280.png` | -13.74, -21.63 | синий/белый контейнеры не дым и не вода |

Тест: `tests/test_gazebo_regression.py`. Позы зафиксированы в тесте; кадры
не перегенерируются, чтобы регрессия ловила изменения детектора, а не
дрейф симуляции.
