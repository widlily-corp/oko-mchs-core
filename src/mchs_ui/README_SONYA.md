# ИНСТРУКЦИЯ ДЛЯ СОНИ (АРМ ОПЕРАТОРА МЧС)

Привет, Соня! Твоя задача — сделать пульт оператора МЧС самым стильным, понятным и живым элементом нашего проекта. Жюри первым делом увидит твой экран.

---

## 1. Как запустить приложение прямо сейчас

Приложение написано на Python (`CustomTkinter`) и запускается прямо из Windows (даже без захода в WSL):

1. Открой терминал в папке проекта:
   ```cmd
   cd src/mchs_ui
   python app.py
   ```
2. Перед тобой откроется темный пульт с картой патрулирования, камерой дрона и телеметрией.

---

## 2. Что внутри приложения уже работает:
* **Интерактивная карта слева:** на ней отображается база МЧС, зона леса, очаг пожара и дрон, который летит по точкам.
* **Экран камеры справа:** живой рендер того, что «видит» дрон.
* **Кнопка «ТЕПЛОВИЗОР»:** переключает картинку в тепловой инфракрасный спектр (псевдоцвета Ironbow/Jet).
* **Панель телеметрии:** заряд батареи, текущая высота, статус полета.
* **Индикатор тревоги:** красная плашка «ПОЖАР ОБНАРУЖЕН!», когда дрон подлетает к очагу.
